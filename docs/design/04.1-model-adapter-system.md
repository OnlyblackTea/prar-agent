## 1. 任务背景

Task 04 LLMRouter 用 **prefix 硬编码 + `default_model_id` Settings 字段** 路由，是过渡实现：

```python
# 当前 router.py
ANTHROPIC_PREFIXES = ("claude-", "anthropic/")
OPENAI_PREFIXES = ("gpt-", "o1-", "o3-", "openai/")
```

主人在 Task 04 review 时拍板：

> "默认 model 不指定，接入什么 model 由用户自己通过前端引导式创建 model adapter；API Key 进 dotenv 文件。"

后续追问"是否支持 contributor 自行添加 adapter 类"，决定引入 **Provider Plugin Registry**（Q7=A）+ **多键 credentials_env**（Q8=A）。

引申 5 个目标：

1. **接入新模型不改代码** — 用户在 UI 里填 provider/model/参数即可
2. **Contributor 加新 provider 不改框架** — 仅新建 `providers/<name>.py` + 一行 import 即可
3. **支持任意凭证形态** — 单 key (Anthropic) / 多 key (AWS Bedrock 的 access_key+secret_key+region) / Azure deployment / Vertex service account 都能塞
4. **Session 显式绑定 adapter** — 新 session 必须选一个 adapter
5. **凭证不入库** — DB 只存环境变量名，运行时解析；DB dump 不泄漏密钥

## 4. 数据模型变更（4.1a）

### 4.1 新增表 `model_adapters`

```python
class ModelAdapter(Base):
    """用户配置的 LLM 接入点。一个 adapter 对应一组 (provider, model, credentials, params)。"""

    __tablename__ = "model_adapters"

    id: Mapped[UUID] = mapped_column(
        primary_key=True, server_default=func.gen_random_uuid()
    )
    name: Mapped[str] = mapped_column(String(64), nullable=False)
    # provider key（如 "anthropic" / "openai" / "openai_compatible" / "bedrock"）
    # 不加 CHECK constraint：合法集由应用层 PROVIDER_REGISTRY 决定（plugin 注册即合法）
    provider: Mapped[str] = mapped_column(String(64), nullable=False)
    model: Mapped[str] = mapped_column(String(128), nullable=False)
    # 凭证 env 名映射：{"api_key": "ANTHROPIC_API_KEY"} 或
    # {"access_key": "AWS_ACCESS_KEY_ID", "secret_key": "AWS_SECRET_ACCESS_KEY", "region": "AWS_REGION"}
    # 仅存 env var 名，运行时由 service 层 resolve；DB dump 零泄漏
    credentials_env: Mapped[dict[str, str]] = mapped_column(
        JSONB, nullable=False, server_default="{}"
    )
    # 非密钥参数：{"base_url": "https://...", "anthropic_beta": "...", "azure_api_version": "..."}
    params: Mapped[dict[str, Any]] = mapped_column(
        JSONB, nullable=False, server_default="{}"
    )
    is_default: Mapped[bool] = mapped_column(
        Boolean, nullable=False, server_default="false"
    )
    is_active: Mapped[bool] = mapped_column(
        Boolean, nullable=False, server_default="true"
    )
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), nullable=False
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True),
        server_default=func.now(),
        onupdate=func.now(),
        nullable=False,
    )

    __table_args__ = (
        UniqueConstraint("name", name="name_unique"),
        # 部分唯一索引：全局至多一行 is_default=true
        Index(
            "model_adapters_default_unique",
            "is_default",
            unique=True,
            postgresql_where=text("is_default = true"),
        ),
    )
```

**关键变化（vs 上一版）**：
- ❌ 移除 `CheckConstraint("provider IN (...)")` — registry 是单一权威来源
- ❌ 移除 `CheckConstraint("base_url 一致性")` — base_url 归 params，由 ProviderSpec.validate_config 在应用层校验
- ❌ 移除 `base_url` 顶层列 — 归并入 `params["base_url"]`
- 🔄 `api_key_env: String(64)` → `credentials_env: JSONB`（多键支持，Q8=A）
- 🔄 `extra_params: JSONB` → 重命名 `params: JSONB`（语义对偶 credentials_env）

### 5.2 `providers/base.py` — Spec 与 Registry

```python
from dataclasses import dataclass
from typing import Any, Callable, Literal

import instructor

from app.llm.types import ResolvedAdapter

FieldType = Literal["text", "url", "secret_env_name", "select"]

@dataclass(frozen=True, slots=True)
class FieldDef:
    """provider 自定义字段的 wizard 元数据。"""
    label: str
    type: FieldType
    required: bool = True
    placeholder: str = ""
    validate_pattern: str | None = None  # regex
    options: list[str] | None = None      # 仅 type="select" 时用

@dataclass(frozen=True, slots=True)
class ProviderSpec:
    """contributor 实现这个 spec 即注入新 provider，无需改框架核心。"""
    key: str                                          # "anthropic" / "bedrock"
    label: str                                        # UI 显示名
    credentials_fields: dict[str, FieldDef]           # wizard 中渲染为 env-var-name 输入框
    params_fields: dict[str, FieldDef]                # wizard 中渲染为普通参数输入
    build_client: Callable[[ResolvedAdapter], instructor.AsyncInstructor]
    validate_config: Callable[[dict[str, Any]], None] = lambda _: None  # 创建时业务校验

PROVIDER_REGISTRY: dict[str, ProviderSpec] = {}

def register_provider(spec_factory: Callable[[], ProviderSpec]) -> Callable[[], ProviderSpec]:
    """decorator：把工厂函数生成的 spec 注册到全局 registry。"""
    spec = spec_factory()
    if spec.key in PROVIDER_REGISTRY:
        raise ValueError(f"Provider {spec.key} already registered")
    PROVIDER_REGISTRY[spec.key] = spec
    return spec_factory
```

### 6.3 router 内部改造

```python
# router.py 改造后
class LLMRouter:
    def __init__(self, settings: Settings) -> None:
        self._settings = settings
        # 缓存键 = (provider, frozenset(credentials.items()), frozenset(params.items()))
        self._client_cache: dict[Hashable, instructor.AsyncInstructor] = {}

    def _client_for(self, adapter: ResolvedAdapter) -> instructor.AsyncInstructor:
        spec = PROVIDER_REGISTRY.get(adapter.provider)
        if spec is None:
            raise LLMTransportError(
                f"Unknown provider: {adapter.provider}",
                model_id=adapter.model,
            )
        cache_key = (
            adapter.provider,
            frozenset(adapter.credentials.items()),
            frozenset(adapter.params.items()),
        )
        if cache_key not in self._client_cache:
            self._client_cache[cache_key] = spec.build_client(adapter)
        return self._client_cache[cache_key]

    async def complete_structured[T: BaseModel](
        self, *, adapter: ResolvedAdapter, ...
    ) -> StructuredResponse[T]:
        client = self._client_for(adapter)
        try:
            parsed, raw = await client.chat.completions.create_with_completion(
                model=adapter.model, response_model=schema, ...,
            )
        except InstructorRetryException as e:
            raise StructuredOutputError(..., model_id=adapter.model) from e
        except Exception as e:
            raise LLMTransportError(..., model_id=adapter.model, cause=e) from e
        return StructuredResponse[T](...)
```

### 6.4 新模块 `app/services/adapter_service.py`

```python
class AdapterService:
    def __init__(self, db: AsyncSession): ...

    async def list(self, *, only_active: bool = True) -> list[ModelAdapter]: ...
    async def get(self, adapter_id: UUID) -> ModelAdapter: ...  # 404 raise
    async def create(self, payload: ModelAdapterCreate) -> ModelAdapter:
        # 1. provider 必须在 PROVIDER_REGISTRY
        # 2. 调 spec.validate_config(payload)
        # 3. 调 spec 的 credentials_fields / params_fields 校验字段完整性
        # 4. INSERT
        ...
    async def update(self, adapter_id: UUID, payload: ModelAdapterUpdate) -> ModelAdapter: ...
    async def delete(self, adapter_id: UUID, *, hard: bool = False) -> None: ...
    async def set_default(self, adapter_id: UUID) -> ModelAdapter: ...
    async def get_default(self) -> ModelAdapter | None: ...

    def resolve(self, adapter: ModelAdapter) -> ResolvedAdapter:
        """根据 spec.credentials_fields 把 credentials_env 解析为真实值。"""
        spec = PROVIDER_REGISTRY[adapter.provider]
        credentials: dict[str, str] = {}
        for field_name in spec.credentials_fields:
            env_name = adapter.credentials_env.get(field_name)
            if not env_name:
                raise LLMTransportError(
                    f"Missing credential field {field_name} for adapter {adapter.name}",
                    model_id=adapter.model,
                )
            value = os.environ.get(env_name)
            if not value:
                raise LLMTransportError(
                    f"Env var {env_name} not set",
                    model_id=adapter.model,
                )
            credentials[field_name] = value
        return ResolvedAdapter(
            id=adapter.id, name=adapter.name, provider=adapter.provider,
            model=adapter.model, credentials=credentials, params=adapter.params,
        )
```

## 9. Frontend Wizard（4.1c，仅契约预览）

引导式流程（消费 GET /api/providers，**不再写死 5 步**）：

1. **Step 1**：调 GET /api/providers，列出所有 registered provider；用户选一个
2. **Step 2**：填 model（自由输入框，可后续做 model 推荐列表）
3. **Step 3**：根据 spec.credentials_fields 动态渲染 N 个 secret_env_name 输入框（带实时 GET /api/env-vars/check?name=XXX 检查 env 是否已 set）
4. **Step 4**：根据 spec.params_fields 动态渲染 M 个普通输入框
5. **Step 5**：调 POST /api/adapters?dry_run=true 校验 → 调 POST /api/adapters/{id}/test 实测 → 命名提交
