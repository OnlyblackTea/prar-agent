# 15.1 mypy 既有错误全量修复

> 前置：M3-15 收口后 `make typecheck` 全局仍有 166 个历史遗留错误。
> 本设计为独立修复任务（用户决策：全量修复，即审计报告方案 A）。

## 1. 背景与目标

M3-15 验收时发现 `uv run mypy src tests` 报 166 个错误，跨 20 个既有文件。
审计结论（证据链见 §3）：**历史遗留技术债**——依赖版本从未变化
（mypy 1.20.2 自 M1-01 起锁定于 uv.lock、SQLAlchemy 2.0.49 未变），
报错文件自 M1/M2 开发期起即未通过全局 typecheck，M2 收口验收时未覆盖此质量门。

**目标**：`make typecheck`（`mypy src tests`）与 `uv run mypy scripts/gen_schema.py` 全部零错误，
且**零运行时行为变化**（纯类型层修复，全部测试保持绿）。

## 2. 范围

修改 **20 个既有文件**（14 测试 + 6 源码 + 1 脚本），**0 新增文件，0 新依赖**。
错误分布：166 = 源码 13 + 测试 150 + 脚本 3，10 种错误码。

| 错误码 | 数量 | 修复模式 |
|---|---|---|
| no-untyped-def | 71 | 补参数/返回注解 |
| union-attr | 46 | `cast(具体节点类型, …)` 收窄 |
| no-untyped-call | 13 | helper 补注解后自动消失 |
| type-arg | 14 | 裸 `dict`/`list` → 带类型参数 |
| list-item | 6 | dict 字面量 → 节点类构造 |
| unused-ignore | 5 | 删掉（cast 取代）或改 `[method-assign]` |
| arg-type | 4 | 传 UUID 代替 str；`list[PlanNode]` 显式注解；cast |
| attr-defined | 4 | `cast(Table, __table__)`；`type[BaseModel]` 类型参数 |
| no-any-return | 2 | `cast` |
| misc | 1 | 生成器 fixture 返回 `Iterator[None]` |

## 3. 根因（审计证据）

- 依赖无变化：`git log -S '1.20.2' -- backend/uv.lock` 显示 mypy 1.20.2 自 M1-01 起锁定；
  SQLAlchemy 2.0.49 从未变过；pyproject/Makefile 近期无改动。
- 代码无变化：报错文件（test_plan_engine.py 等）最近 commit 均远早于 M3。
- 结论：这些文件**自创建起**就未通过 mypy（strict 下测试文件同样受检），
  属 M1/M2 收口时的验收盲区，非升级回归。

## 4. 修复原则

1. **零行为变化**：只改注解、cast、类型构造等价替换；不改变任何运行时值。
2. **正确收窄优先**：union 访问用 `cast`，禁止新增裸 `# type: ignore`。
3. **保留既有 ignore 风格**：唯一保留的 ignore 是 monkeypatch 实例方法的
   `# type: ignore[method-assign]`（mypy 官方建议的窄化 code）。
4. **不扩大质量门范围**：Makefile 不变（`typecheck` 仍为 `mypy src tests`）；
   gen_schema.py 单独验证，不加入 Makefile。
5. 测试文件在 mypy 检查范围内，注解补全与既有良好测试（如 test_ws_streamer.py）风格一致。

## 6. 决策项

- **Q1 SessionNotFoundError 传参**：comment_service L31 改传 UUID（而非放宽异常签名接受 str）。
  理由：异常契约明确绑定 UUID，调用点参数本就是 UUID，消息输出不变，零行为变化。
- **Q2 `_mock_response` 参数类型**：各测试文件内用精确 union（test_plan_engine 用
  `PlanDocument | CriticResult`，test_review_merger 用 `MergerResult`），不用 Any。
- **Q3 `_PLAN_V1` dict 节点改类构造**：HeadingNode/ParagraphNode 构造与 dict 字面量经
  pydantic discriminator 解析后等价；`model_dump()` 输出一致，DB 落库与 model_validate 回读不变。
- **Q4 unused-ignore 处置**：test_review_merger 的 3 处用 cast 取代后删除 ignore；
  test_comment_service 的 2 处按 mypy 建议窄化为 `[method-assign]`（保留 ignore 是
  monkeypatch 实例方法的标准做法）。
- **Q5 gen_schema.py 是否加入 Makefile typecheck**：不加。Makefile 范围不动，
  脚本单独以 `uv run mypy scripts/gen_schema.py` 验证并在本设计验收中覆盖。
- **Q6 get_logger 返回类型**：`cast(structlog.stdlib.BoundLogger, …)` 保持既有签名，
  不改成 union（调用方 `_log.info(...)` 两种类型均可用，但改签名会放大 diff，无收益）。
